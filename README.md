# The Elsinore Archives — GitHub Pages edition

A fictional, interactive Hamlet archive mystery.

## Publish
1. Upload ALL files from this folder to the root of a GitHub repository (do not upload only index.html).
2. GitHub repository Settings → Pages → Deploy from a branch → main → /(root).
3. Open the published URL.

## Game test route
- Enter `www.elsinore-royal.dk` on the home page.
- Select either snapshot.
- In 2026, open Admin and use `prince.hamlet` as both username and password.
- Open Deleted Articles and My Journal.

## Notes
- All content is fictional and the article/journal prose is DRAFT for collaboration.
- This is a static puzzle login, not a secure authentication system. Credentials and page contents are visible in source files; appropriate for a game, not private data.
- 1599 archive has 5 date links; 3 available, 2 missing. 2026 archive has 4 accessible articles. The missing records correspond to two deleted medical articles.
- Horatio is a regular publisher, not an administrator; he used Hamlet's admin account.
- HTML files share `style.css` and `game.js`. Edit these to customize the site.
